## 3–4 minutes · ARC quota and copied slots

“Malformed proof causes zero arrivals, followed by valid owner access. One client's five-use exhaustion leaves another client's allowance usable. A regenerated proof for an already claimed slot is refused. ARC does permit a copied credential's first use to win. Repeated-slot defense and rightful-holder identification are different properties.”

## 4–5 minutes · Holder-bound profile

Run the separate holder theft scene.

“This profile issues a fresh P256 possession key per token. Redemption binds the token, server nonce and request to a signature. Copying only token bytes causes zero origin arrivals. The owner then succeeds. Twenty duplicate requests race across two production gateway workers and produce one additional arrival.”

“A stolen complete valid signed request can race the owner. Private-key compromise also defeats possession binding. These limits remain explicit.”

## 5–6 minutes · Evidence and lifecycle

“The private origin independently counts requests received and resources served. We require both counters to agree with delivery, zero generation mismatches and matching gateway claims. An uncertain outcome consumes possible allowance and never earns an automatic refund.”

Show reset and fresh start.

“The supervisor closes admission on lease, dependency or state uncertainty. Confirmed fencing and exit precede replay-state discard. A fresh experiment gets new keys and state. The server controls the fixed window.”

## 6–7 minutes · Trust and tradeoffs

“The deployed prototype runs on this laptop's private Docker networks. The host, controller and intact replay state are trusted. Clocks must be trustworthy and non-regressing. ARC is pinned research code with a documented narrow P256 correction. Private issuance and verification share the ARC operator, so operator visibility and timing correlation remain privacy costs.”

“The contribution is a working protected-resource gateway combining anonymous quotas, shared atomic replay enforcement, measured equal-budget behavior and a separate holder-bound profile. The measurements describe this controlled workload. Broader capacity and venue rehearsal remain separate human work.”
