# Public test-fixture attribution

The public RFC 9578 vector is derived from Cloudflare's pinned Privacy Pass test data. Copyright (c) 2023 Cloudflare, Inc. Licensed under Apache License 2.0; see `APACHE-2.0.txt`. The fixture records exact source URL/commit and SHA-256. Only public SPKI/token/challenge/request/response/nonce were retained; no source private key, blinding inverse or fixed-signing configuration.

The policy fixture is independently generated by this repository's Python stdlib script, using that public test key. Every fixture is test-only, excluded from runtime images and must never be used as a live accepted key/credential. Published fixed tokens are not secret credentials.
